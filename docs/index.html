Domínio Core

Módulos altamente desacoplados construídos para suportar alto tráfego e regras de negócio complexas de uma oficina mecânica.

Gestão de Clientes

Suporte para PF e PJ, com validações complexas de documentos (CPF/CNPJ) implementadas como Value Objects.

Controle de Veículos

Vínculo cliente-veículo com suporte flexível a formatos de placas antigos e do padrão Mercosul.

Ordem de Serviço (O.S.)

Coração do sistema. Rastreamento de status, integração com serviços, consumo de peças e insumos.

Gestão de Estoque

Rastreio completo do histórico. Entradas, saídas, ajustes e devoluções garantindo integridade de dados.

Autenticação JWT

Segurança robusta baseada em Roles (Administrador, Funcionário) com tokens de 8h de expiração via HMAC SHA256.

Paginação Nativa

Respostas HTTP 206 (Partial Content) para listagens volumosas, otimizando latência e banda de rede.

Design Pattern

Arquitetura Limpa
& DDD

O sistema foi construído em 4 camadas distintas, garantindo que as regras de negócio permaneçam agnósticas a frameworks ou banco de dados.

  • Repository & Unit of Work Coordenação transacional segura para o Entity Framework Core.
  • Command Result Pattern Padronização de retornos da API contendo Dados, Mensagens e Status HTTP.
  • DTO Pattern Isolamento total entre o modelo de domínio (Entities) e a exposição externa via API.
1. API Layer (Controllers)

Autenticação JWT, Recebimento de requests, Validações primárias.

2. Application Layer Services & DTOs

Orquestração de lógica, mapeamento de objetos, regras de aplicação.

3. Domain Layer Core Business

Entidades ricas, Agregados (Cliente, O.S, Estoque), Value Objects (CPF/CNPJ, Email).

4. Infrastructure Layer Data Access

EF Core, SQL Server 2022, Migrations, Repositories Concretos.
